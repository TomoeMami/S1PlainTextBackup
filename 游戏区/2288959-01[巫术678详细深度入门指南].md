————————————————————————————————————6代————————————————————————————————————

最好的是sfc版，只有日文，如果看不懂可以用roomhack的英化补丁，已知bug有：个别战斗消息错乱（比如对后期部分敌人即死会出现日文，但是并不影响游戏），snesx1.60后的版本最后一个人的头像如果是自创的存档读档随机错乱，1.53版本没这个问题。

存档问题：

sfc存档不和dos互通，无法继承，这样前面下载的通关存档就有用了，根据自己的结局，用修改器修改6代存档，然后导入7代。因为7是根据算法弱化6代的属性，还会丢失装备，因此直接修改7会直接碾压，推荐先改6然后导入7。

修改器有多个，我推荐6代存档修改器用baneedit，7用dscheat。

———————————————————————————————————————7代自动地图————————————————————————————————————

7代的自动地图坑非常多，我踩完以后直接给实操能用的方法。

这个mod叫auto-map，通过钩子技术读取内存实现实时地图，如果不用，7代自己有map技能，提高以后使用map kit也能展示附近地图，只是远没有这个mod方便，追求硬核的可以不用，反正我是离不开了。

这个mod有两个版本，一个是原始版，不适配现在的windows系统，起码win10和win11不行，能读出内存数据，但是无法渲染，所以我推荐新版的Wiz67_AutomapMod_build003:
[https://dungeoncrawl-classics.co ... rdry-7-map-details/](https://dungeoncrawl-classics.com/wizardry-series/7-crusaders-of-the-dark-savant/wizardry-7-map-details/)

read me有安装方法，不过我这里还是说一下，首先在conf文件里加上这些（放在最后就行，我的conf文件已经有了）

[automap]

enable=true

width=512

height=512

show_tooltips=true

hide_in_dark_zones=true # optional

然后把这个mod的文件全部复制到dosbox的目录（最好备份一下原来的）

—————————————————————————————————————dosbox简易入门——————————————————————————————：

dosbox本质就是模拟一个dos环境，玩游戏只需要知道把自己的磁盘挂载成虚拟盘符就行，这是我的7代运行batch（就是几个指令打包而已）

[@Echo](https://stage1st.com/2b/home.php?mod=space&amp;uid=118165) off

set GAME_PATH=E:\games\dos\roms\Wizardry7

set SAVE_PATH=E:\games\dos\roms\Wizardry7\save

#set CHEAT_PATH=E:\games\dos\tools\wiz\dscheat

"E:\games\dos\DOSBox Staging_wiz\dosbox.exe"  -conf "E:\games\dos\DOSBox Staging_wiz\dosbox_wiz7.conf"  -c "mount c %GAME_PATH%"  -c "mount d %SAVE_PATH%" -c "c:"

这句是指出dosbox要运行的配置文件：

-conf "E:\games\dos\DOSBox Staging_wiz\dosbox_wiz7.conf

如果不填，他会默认读取c盘app文件夹下面的，不好管理，因此最好自己搞一个放游戏目录，分门别类，所以我这个conf文件的名字加了wiz7后缀，附件里的就是这个。

 -c "mount c %GAME_PATH%"

-c是执行命令，mount就是挂载，这句的意思是把game path挂载成c盘，game path在前面定义了。同理后面一句就是把存档文件的目录配置成d盘，这样c和d隔离开方便管理

后续我会讲怎么用dscheat（baneedit有手就行），另外还会讲8代怎么装patch和expand。

感谢上面几位的解读，那么就从7开始好了。

巫术6当年在贴吧看过图文流程，个人印象就是双法师得天下，那个扭曲的谎言剧情也挺震撼的，78就是完全不了解了。

听说8代战斗太慢了，个人这10几年来主玩五色试炼，习惯了5秒一场遭遇战的节奏，大概率很难接受不了那个节奏，所以就云一下好。

现在让推荐巫术的话（不含世界树和东方的迷宫这种wizlike类），个人就三个推荐：武神零，冬宫2和五色试炼，分别是古典巫术纯3D化，人物培养和系统扩展三个方面的代表。包括本家1-5在内，以及其他外传和大部分衍生作只有考古意义，大概率是折磨。

有人提五色试炼，我个人觉得这个游戏主要的玩点在民间剧本，官方那几个都是抛砖引玉向的，论质量还真难与民间的抗衡。

而汉化嘛，这游戏本身是一个剧本运行器，包括官方剧本在内的所有剧本都是以一个单独的加密文件存放的，所以你得先破解这个加密才行。我个人的意见就是有这功夫不如边玩边截图机翻，大部分剧本的剧情都是口水化，早期剧本里那些文字输入题也是作者自high，真正有文字功底的剧本很少。

另外，手动绘图可以用“方眼纸”这个软件，算是巫术玩家最常用的软件之一了。
