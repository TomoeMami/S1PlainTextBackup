简单做个记录，在开发过程中禁止ai使用的开源游戏项目：

1. UZDoom，著名Doom Source port和游戏引擎，前身GZDoom，因为ai使用赶走其创始人并自立门户。

极为严苛，禁止使用生成式ai修改、编写代码、提供思路、写注释以及其它任何生成式ai辅助功能。[https://github.com/UZDoom/UZDoom/blob/trunk/CONTRIBUTING.md](https://github.com/UZDoom/UZDoom/blob/trunk/CONTRIBUTING.md)

2. Cataclysm: Dark Days Ahead，著名古典roguelike游戏。

所有源自诸如 ChatGPT 之类的 LLM 的内容（包括但不限于代码、配置、问题和 PR 文本、研究和测试结果）均不被允许。[https://github.com/CleverRaven/C ... ter/CONTRIBUTING.md](https://github.com/CleverRaven/Cataclysm-DDA/blob/master/CONTRIBUTING.md)

3. Gobot Engine，著名游戏引擎，Unity暴雷之后独立游戏开发者的应许之地。

稍微宽松，禁止使用实质性（substantial）提交生成式ai使用的代码。禁止与人交流时使用ai生成的文本等，禁止使用ai agent进行pr等，但可以辅助。[https://contributing.godotengine ... ribution_rules.html](https://contributing.godotengine.org/en/latest/development/contribution_rules.htmlhttps://contributing.godotengine.org/en/latest/development/contribution_rules.html)

4. Endless Sky，还算有名的开源太空游戏。

大体禁止一切生成式ai使用。[https://github.com/endless-sky/e ... ocs/CONTRIBUTING.md](https://github.com/endless-sky/endless-sky/blob/master/docs/CONTRIBUTING.md)

欢迎补充。
