RetroArch里还有两个核心，试了gles2黑屏，ParaLLEI N64即使用8gen2开头也卡爆，就没再测试了

1.M64Plus FZ

- 直接运行战斗动画有些黑边，到emulation profile里改成GlideN64-Accurate就行，他默认是Fast那个就有黑边

- 加速只能到最大300%，一般够用了，但这作不能关战斗动画，如果你还想快点就只能上全能了

- 加速按键只支持按着加速，和按加速减速键来永久加减速，和RA有点不同。其实操作起来还是可以的。

2.RetroArch Mupen64Plus-Next gles3

- 就是全能模拟器，对于习惯了的人来说很好，比如加速支持常规按着加速和按一下切换加速

接下来是测试的机子情况

RG476H

- M64Plus FZ ：用GlideN64-Accurate或Fast的话，在标题画面那堆火和开头飞出文字卡爆，进到游戏里还算正常。不知道后面还有没有开场这样的卡爆场景

- RA：开场正常运行，加速也很流畅，我感觉300%~400%都有，感觉很好。但我遇到了个问题，注意看本贴最后。

NOVA

- M64Plus FZ：用GlideN64-Accurate很流畅，其他没测了

- RA：加速不限帧的话我目测能比476快一点吧？但我大约用四倍玩，所以更快了也没用

接下来是重点

玩RA遇到的奇怪问题，我不知道是机子原因还是RA版本原因，反正解决方法记录一下

如果你也遇到这两个毛病可以试试

我用nova玩会遇到<strong>休眠唤醒回来所有操作按键都无法操作</strong>的问题，

解决方法：

Settings -&gt; Input -&gt;Polling Behavior，把Late改成Early

就可以了

我用476玩会遇到<strong>休眠回来有操作有音乐但黑屏</strong>的问题，

解决方法：

按这个：[https://www.reddit.com/r/RetroAr ... een_on_android_fix/](https://www.reddit.com/r/RetroArch/comments/1n5k98e/n64_audio_but_black_screen_on_android_fix/)

先运行游戏，然后quick menu -&gt; Core Options -&gt; RDP Plugin 从 GLideN64 改成 Angrylion，然后下面的RSP Plugin保持HLE（默认就是）

接着去 Settings  -&gt; Video -&gt; Output 把gl改成Vulkan

然后就不会黑屏了。

**重点来了，改成Angrylion后虽然解决了黑屏，但整个加速效率下降很多，

特别是一些多点3D的战斗场景，Nova我测了可能降到200%~300%，476明显下降到150%附近只比正常快一点，毕竟不能关战斗的机战，对于依赖加速来玩的人来说影响很大

因为我Nova用GLideN64不黑屏，所以我决定用Nova玩，当然最后这一点我也不知道是机器的原因还是RA版本原因

<strong>附录：M64Plus FZ改按键的方法</strong>

和常规的模拟器设置思路不太一样，免得有人找不到方法：

配置 —— 控制器配置 ，然后右上角 +新建 ，新增一个你自己的按键配置，名字随便，里面就可以随便改按键了

改好后到配置 —— Select Profile里，控制器1配置，选成你建的这个就行
